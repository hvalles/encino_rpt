<objective>
Añadir entrada multi-formato a `Report` mediante un módulo `encino_rpt/readers.py` con un protocolo `Reader`, un registro de readers (built-in + custom), y auto-detección de tipos. `Report` gana `read(...)` y `register_reader(...)` sin tocar `Report(rows=...)`.
</objective>

<action>
Crear `encino_rpt/readers.py` con:

1. Protocolo `Reader` (`typing.Protocol`) con método `read(self, source, **opts) -> list[dict]`.
2. Registro módulo-level: `_READERS: dict[str, Reader] = {}`, funciones `register_reader(name, reader) -> None` y `get_reader(name) -> Reader` (lanza `ValueError(f"reader no registrado: {name!r}")`).
3. Función de auto-detección `_coerce(value) -> Any`: solo si `isinstance(value, str)`. Orden: strip; si `""` o lower en `("null","none")` → `None`; si lower `"true"` → `True`, `"false"` → `False`; `int(s)`; `float(s)`; si todo falla → devolver el string original. Las excepciones `ValueError` de `int`/`float` se capturan.
4. Readers stdlib (registrados por defecto en import del módulo):
   - `csv`: usa `csv.DictReader` con `delimiter=","`; acepta ruta (str/PathLike) o file-like (`.read()` devuelve str; envolver en `io.StringIO`). Aplica `_coerce` a cada valor salvo `coerce=False`.
   - `tsv`: igual con `delimiter="\t"`.
   - `json`: `json.load` sobre el source (ruta o file-like o str raw). Espera lista de objetos → `list[dict]`.
   - `jsonl`: una línea por objeto, `json.loads` por línea.
   - `tuples`: `source` es `list[tuple]`; requiere `columns` (list[str]); produce `[dict(zip(columns, row)) for row in source]` (lanza `ValueError("`columns` requerido para reader 'tuples'")` si falta).
   - Los readers que aceptan rutas usan `pathlib.Path`/`open(...)` y un helper interno `_to_text(source)` que normaliza ruta|file-like|str → texto.
5. Función pública `read(source, format=None, *, coerce=True, columns=None, **opts) -> list[dict]`: resuelve `format` por extensión si es `None` (`.csv`→csv, `.tsv`→tsv, `.json`→json, `.jsonl`→jsonl, `.xlsx`/`.xlsm`→excel); si no se puede resolver, `ValueError`. Despacha a `get_reader(format).read(source, coerce=coerce, columns=columns, **opts)`.

Docstrings Google en español en cada elemento público. Import `from __future__ import annotations`. Sin dependencias nuevas (csv/json/io/pathlib/typing stdlib).
</action>
<acceptance_criteria>
- `encino_rpt/readers.py` existe y define `Reader`, `register_reader`, `get_reader`, `read`, `_coerce`.
- `_coerce("100") == 100`, `_coerce("100.5") == 100.5`, `_coerce("true") is True`, `_coerce("") is None`, `_coerce("N/A") == "N/A"`, `_coerce(5) == 5` (no-str intacto).
- `read("{\"a\":1,\"b\":2}")`... no: `read([("x",1)], format="tuples", columns=["c"])` devuelve `[{"c":1}]`.
- `uv run ruff check encino_rpt/readers.py` → limpio.
</acceptance_criteria>
</task>
